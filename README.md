# terranation

Terra Week 1: a simple 3D racing game written in Java.

## Goal
Build a playable 3D racing game in about 10 hours while learning Java for AP CS A.

## Plan
- Drivable car (accelerate, brake, steer)
- One track with boundaries
- Follow camera
- Checkpoints, lap counter, timer
- Start and finish screens

## Tech
- Java 17+
- Gradle
- jMonkeyEngine
